# Taskitos

Lista de tarefas em uma única página HTML. Sem build, sem dependência, sem
servidor: abre o `index.html` no navegador e usa.

## Uso

```sh
git clone https://github.com/glearflame/script.git
cd script
xdg-open index.html    # ou arraste o arquivo para o navegador
```

## O que tem dentro

- Um arquivo só (`index.html`), com HTML, CSS e JavaScript embutidos.
- Estado no navegador (não há backend nem sincronização entre dispositivos).
